You are a game level designer for a Snake game built with Flame in Flutter.
Your job is to generate all 100 levels as a Dart file.

## Level Structure
Each level is a Map with these fields:
```dart
{
  'level': int,           // 1 to 100
  'speed': int,           // Timer interval in ms (lower = faster)
  'timeLimit': int,       // Seconds to complete level
  'appleTarget': int,     // Always 30
  'obstacles': List<Map>, // [{x: int, y: int}, ...] grid positions
}
```

## Grid Size: 20x20 (columns 0-19, rows 0-19)

## Difficulty Progression Rules

### Speed (ms interval between moves)
- Levels 1-10:   400ms (very slow)
- Levels 11-20:  350ms
- Levels 21-30:  300ms
- Levels 31-40:  260ms
- Levels 41-50:  220ms
- Levels 51-60:  190ms
- Levels 61-70:  165ms
- Levels 71-80:  145ms
- Levels 81-90:  130ms
- Levels 91-100: 120ms (very fast)

### Time Limit (seconds)
- Levels 1-10:   120s
- Levels 11-20:  110s
- Levels 21-30:  100s
- Levels 31-40:  90s
- Levels 41-50:  80s
- Levels 51-60:  75s
- Levels 61-70:  70s
- Levels 71-80:  65s
- Levels 81-90:  60s
- Levels 91-100: 55s

### Obstacles (grid positions, never block center spawn area 8-12,8-12)
- Levels 1-5:    0 obstacles
- Levels 6-15:   2-4 obstacles (edges only)
- Levels 16-30:  4-8 obstacles (edges + some middle)
- Levels 31-50:  8-14 obstacles (forming simple patterns)
- Levels 51-70:  14-20 obstacles (L-shapes, corridors)
- Levels 71-85:  20-28 obstacles (maze-like patterns)
- Levels 86-100: 28-35 obstacles (complex mazes, tight paths)

## Rules for Obstacle Placement
- Never place on positions (9,9), (10,9), (10,10), (9,10) — snake spawn area
- Never fully block the path (always leave navigable route)
- Obstacles should feel like walls, barriers, and maze sections
